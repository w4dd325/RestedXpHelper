# Rested XP Helper

**Rested XP Helper** is a lightweight World of Warcraft Classic Anniversary / Burning Crusade Classic Anniversary addon that makes rested XP easier to track.

It provides a standalone on-screen rested XP bar, an estimate of the time remaining until the 150% rested XP cap, and optional logout reminders.

## Features

- Standalone Rested XP progress bar
- Current Rested XP percentage
- Estimated time until fully rested
- `FULLY RESTED` indicator at the 150% cap
- Move the bar anywhere on screen
- Resize the bar horizontally
- Lock the bar in position
- Keep the bar horizontally centred
- Reset the bar to its default position
- Optional logout reminder outside a resting area
- Suppress reminders when fully rested
- Suppress reminders at maximum level
- Saved settings between sessions

## Commands

Use `/rested` or `/restxp` to open **Rested XP Helper** settings.

## Installation

The recommended installation method is CurseForge once the addon is published.

For manual installation, copy the `RestedXpHelper` folder to:

`World of Warcraft/_anniversary_/Interface/AddOns/RestedXpHelper`

Then enable **Rested XP Helper** from the AddOns menu.
