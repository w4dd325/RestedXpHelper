# Changelog

All notable changes to **Rested XP Helper** will be documented here.

## v1.0.0

### Initial Release
- Initial release of **Rested XP Helper** for WoW Classic TBC Anniversary.
- Added a standalone Rested XP progress bar.
- Added current Rested XP percentage display.
- Added an estimated time until the 150% rested XP cap.
- Added a **FULLY RESTED** indicator when the rested XP cap is reached.
- Added movable and horizontally resizable bar positioning.
- Added an option to lock the bar.
- Added an option to keep the bar horizontally centred.
- Added a reset-position button.
- Added optional logout reminders when outside a resting area.
- Added options to suppress reminders when fully rested or at maximum level.
- Added `/rested` and `/restxp` commands to open the settings window.
- Added persistent settings using SavedVariables.
- Added an addon-loaded message to the chat window.
